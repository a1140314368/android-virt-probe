# 环境异常信号目录

检测对象是当前 Android 运行环境，不是本应用自己的签名、安装来源或 DEX 完整性。
用户界面只显示短句：结论、实际值、参考值、建议。原理、误报和出处留在这里以及 `rawEvidence` / `sourceAttribution`。

未命中不能证明环境正常。Root 或 Hook 线索也不等于恶意。看不到路径不等于没有隐藏框架。
权限被拒绝记为「无法检查」，不当成正常，也不当成命中。

筛选顺序：证据是否明确、无特权能否读到、误报是否可控。VPN、开发者选项、无障碍、外接键鼠只记录，不单独当异常。

## 未实现 / 需特权

| 项 | 原因 |
| --- | --- |
| 执行 `su` 或 `which su` | 可能弹出授权或改变系统状态，不做 |
| Play Integrity、SafetyNet | 闭源或需 Google 服务，不引入 |
| 本应用签名、安装来源、DEX 完整性、FLAG_DEBUGGABLE | 产品明确排除自保护 |
| 用户 CA 证书枚举 | `/data/misc/user/0/cacerts-added` 对普通应用通常不可读。读不到不能编造成 0 |
| KernelSU / APatch 的内核特征、Magisk deny list | 需要 root 读内核或管理器私有数据 |
| Frida 默认端口主动连接 | 会访问本地端口并拖慢扫描，且端口可改。当前只看 maps |
| 全盘搜索 su | 无权限且误报高 |

## 模拟器预期

API 35 模拟器常见 `test-keys` 或 `ro.debuggable=1`，因此 `rt.build.trust` 可能命中。那只说明它是测试系统，不能当成「已在真机验证 Root」。没有真 Root、真 Magisk、真 Frida 时，对应命中只来自规则夹具。
